### SELECTED PROJECTS

**[FacilityFix](https://github.com/hmmlavi/FacilityFix)** · *Flask, Python, SQLite*  
A facility issue reporting and tracking system for colleges. It gives students and staff one place to report problems, while coordinators can review requests, manage priorities and track resolutions.

**[Sortify Desktop](https://github.com/hmmlavi/sortify-desktop)** · *Windows, Python, AI*  
A desktop tool that understands files and suggests meaningful filenames. Review suggestions, safely rename files in batches, and undo changes through local history.

**[Veylo](https://github.com/hmmlavi/Veylo)** · *Web, TypeScript*  
An offline-first habit tracker focused on calm, consistent routines. Includes scheduling, streaks, completion calendars, progress summaries and a rule-based daily planner.

**[Pustakalaya LMS](https://github.com/hmmlavi/Pustakalaya-LMS)** · *Flask, SQLite*  
An offline-ready library management system with catalog search, inventory, members, circulation, reservations and fine handling, plus reports and data export.

**[SaBuddy](https://github.com/hmmlavi/SaBuddy)** · *Android, Gemini*  
A social content planning workspace for ideas, captions, scripts and content calendars, with optional AI-assisted generation and offline fallback.
