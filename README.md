<h2 align="center">⌂ PROJECTS FROM MY WORKSHOP ⌂</h2>

<h3>01. FacilityFix</h3>
<p>
  A web-based college facility issue reporting and tracking system built with Python, Flask, and SQLite.
  Students, faculty, and staff can report problems, while coordinators review issues, manage priorities,
  update statuses, and record resolutions.
  It replaces scattered informal reports with one organized workflow and a clear history for every issue.
  <br/>
  <a href="https://github.com/hmmlavi/FacilityFix">Visit project page »</a>
</p>

<h3>02. Sortify Desktop</h3>
<p>
  A Windows desktop app that makes filenames meaningful by reading documents, spreadsheets,
  presentations, and images.
  It suggests clearer names through a local heuristic engine or a configured OpenAI-compatible AI endpoint.
  Review and edit suggestions before applying them, with collision checks, safe batch renaming,
  local history, and undo.
  <br/>
  <a href="https://github.com/hmmlavi/sortify-desktop">Visit project page »</a>
</p>

<h3>03. Veylo</h3>
<p>
  A calm, private habit tracker designed to turn small daily actions into consistent routines.
  Create and schedule habits, track streaks, explore completion calendars, and review weekly,
  monthly, and yearly progress.
  It also includes a rule-based daily planner, multiple themes, and offline-first functionality
  that keeps personal habit data on-device.
  <br/>
  <a href="https://github.com/hmmlavi/Veylo">Visit project page »</a>
</p>

<h3>04. Pustakalaya LMS</h3>
<p>
  An offline-ready library management system built with a Flask web interface and a local SQLite database.
  It combines catalog search, physical-copy inventory, branch management, member accounts,
  circulation, reservations, and fine handling.
  Operational reports, validated data imports, CSV exports, and Windows packaged builds
  make it practical for local use.
  <br/>
  <a href="https://github.com/hmmlavi/Pustakalaya-LMS">Visit project page »</a>
</p>

<h3>05. SaBuddy</h3>
<p>
  An Android app for planning and drafting social media content, from early ideas to ready-to-edit captions and scripts.
  Organize Reels scripts, post and carousel outlines, captions, hashtags, saved content,
  and a content calendar in one workspace.
  It supports Gemini-powered generation when configured, offline generation as a fallback,
  brand settings, and manually maintained analytics.
  <br/>
  <a href="https://github.com/hmmlavi/SaBuddy">Visit project page »</a>
</p>
